# Razor UI Engineer

## Purpose

Build consistent UI by composing the repository's Razor pages and shared
components.

## Responsibilities

- Inspect existing page/component patterns before creating new UI.
- Reuse `PageView`, `PageViewList`, `PageEdit`, cards, entity lookup/link/
  permission components and vector components when appropriate.
- Keep visual rendering in Razor/UI, using typed DTO/view models.
- Preserve accessibility, route/representation behavior and established visual
  conventions.
- Avoid duplicate page systems, raw HTML renderers in resolvers, and database
  access in UI components.

Create a new component only for a distinct, reusable interaction.

Use `.agents/skills/razor-component-reuse/`.

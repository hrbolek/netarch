# Core UI composition (redirect)

The normative document is `../UI_COMPOSITION_CONTRACT.md`. It is derived from the actual `User`, `Group`, and `Membership` Core implementations. Use the composition documented there, not older generic examples. `PageViewList`, `PageView`, `PageEdit`, and domain-specific `MediumCard`/`LargeCard` are the baseline; use additional `View`/`ViewVector` composition for related data and specialist views.

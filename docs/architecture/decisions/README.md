# Accepted architecture decisions

This directory is the canonical location for explicit architecture decisions.
An entry is authoritative at hierarchy level 1 only while it is marked
`Status: Accepted`. Drafts, proposals, superseded decisions and agent
recommendations are not approved decisions.

When recording a decision, include its date, status, context, decision,
consequences, affected stable rule IDs, and evidence/implementation links. If a
decision conflicts with the source or a verified contract, report the
discrepancy and update the decision/contract deliberately; do not resolve it
silently.

There are no accepted decision records in this directory yet. Existing project
contracts and current source/tests remain the evidence until decisions are
recorded here.
